Assignment 4 Code Explanation

This document explains how the project matches the grading rubric for Assignment 4: MVC structure, MongoDB, Mongoose model, post display, post creation, asynchronous deletion with fetch, error handling, Git work, and README documentation.

Project Flow

The app starts in server.js. It loads environment variables from .env, creates the Express app, enables JSON/body parsing, configures sessions, serves static frontend files, mounts route files, connects to MongoDB through connectDB(), and then starts listening on the selected port.

Function Locations

MongoDB Connection

config/db.js contains connectDB(). This is the only place responsible for connecting to MongoDB. It reads MONGO_URI from .env, which keeps the database connection string out of Git.

Post Model

models/postModel.js contains the Mongoose schema. The required assignment fields are:

  • title - required string
  • content - required string
  • author - required string
  • createdAt - created automatically by timestamps: true
  • updatedAt - updated automatically by timestamps: true

Loading Posts

controllers/postController.js has getPosts(). It calls Post.find().sort({ createdAt: -1 }) and returns { success: true, posts }. This proves posts are loaded from MongoDB, not from an array in server memory.

Creating Posts

createPost() in controllers/postController.js validates title, content, and author. If one is missing, it returns status 400. If the data is valid, it calls Post.create() and returns the created post.

Deleting Posts

deletePost() in controllers/postController.js handles DELETE /posts/:id. It checks whether the id is a valid MongoDB ObjectId. Then it calls Post.findByIdAndDelete(req.params.id). If no post exists, it returns { success: false, message: "Post not found" } with status 404. If deletion succeeds, it returns { success: true, message: "Post deleted successfully" }.

Browser Fetch Delete

Website-for-ph-v4/scripts/Feed.js contains the browser-side deletePost(postId) function. It sends:

fetch(`/posts/${postId}`, { method: "DELETE" })

If the response is successful, it removes the post element from the screen with document.getElementById(`post-${postId}`).remove(). This satisfies the requirement that deletion happens without refreshing the page.
